# Vitrum Design Language

Status: Phase 0 — working draft. Open questions are marked [OPEN] and get
answered in design sessions, then locked in.

## 1. Core statement

> [OPEN] One or two sentences that define Vitrum's look. Draft: "Light,
> glass, and depth — an operating system that feels like looking through
> morning air."

## 2. Color & mood

- [OPEN] Default theme: bright airy aurora (Longhorn's default mood) or dark glass?
- Aurora gradient palette: which hues are ours? (Teal/blue/green family proposed.)
- Accent color system: single accent vs per-app accents?

## 3. Glass

- Blur intensity: full frosted vs subtle?
- Reflections and highlights on window chrome: how strong?
- Borders: luminous edges (Vista) vs minimal hairlines?

## 4. Layout

- Taskbar: bottom (familiar) or top? Centered icons or left?
- Start/launcher: menu, fullscreen, or something new?
- System tray & clock placement.
- **The reimagined sidebar** (our signature, from Longhorn): what lives in it?
  Widgets? Notifications? Both? Can it hide?

## 5. Windows

- Title bar style: glass with glowing text? Button shapes and placement?
- Aero Snap: keep the drag-to-edge behavior?
- Window overview / exposé equivalent: our take?
- Alt+Tab switcher style.

## 6. Signature elements

- [OPEN] The 3-second test: what one thing makes a screenshot unmistakably
  Vitrum and not Windows?
- Login/lock screen concept.
- Boot splash concept.

## 7. Iconography & typography

- Icon style: glossy 3D (Vista era) vs flat with depth? Original set, drawn for Vitrum.
- Font pairing: UI font and monospace. (No Segoe UI — original choices only.)

## 8. Motion

- Animation language: calm and physical? Snappy?
- Window open/close/minimize transitions.
- Boot → login → desktop sequence feel.

## 9. Apps (forked, restyled)

- Priority order: file manager, terminal, text editor, image viewer, settings.
- Fork candidates to evaluate per app.
- How deep does restyling go: theme-only, or layout changes too?
